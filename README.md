One absurd clause, hidden deep inside a terms-of-service agreement: deadpan
legal boilerplate that quietly turns absurd. The entry writes a single
original English sentence (192 characters) to `/output/entry.txt`.

> Users agree that any dispute arising under this agreement shall be settled by arm-wrestling our legal counsel, Brenda, in the parking lot at dawn, and the loser buys breakfast for the pigeons.

## Run it

```sh
node main.ts
```

`main.ts` writes the clause deterministically — Node 22 standard library
only, no network, no randomness: the same bytes on every run.
